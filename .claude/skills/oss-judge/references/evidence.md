## 2. 상위상 vs 하위상 — 무엇이 갈랐는가 (수상작 70팀 실측)

표본: 상위상(대상·금상·은상) 12팀 / 중위상 29팀 / 우수작(무관) 43팀

| 축 | 상위상 | 중위상 | 우수작 | 변별력 |

| **사용자가 개발자인가** | **12/12 = 100%** | 79% | 56% | ★★★ 최강 |
| **소비자 서비스 비율** | **0%** | 21% | 40% | ★★★ 최강 |
| GitHub 스타 중앙값 | 36.5 | 3 | 1 | ★★★ (단, 아래 주의) |
| 패키지 레지스트리 배포 | 라이브러리형 전원 | 일부 | 드묾 | ★★ |
| 레포 생성~제출(중앙값) | 5.3개월 | 1.6개월 | 1.7개월 | ★★ |
| 커밋 수 중앙값 | 350 | 180 | 179 | ★ 약함 |
| **기여자 수 중앙값** | 3 | 4 | 5 | ✗ **역전** |
| **README 크기 중앙값** | 6.6KB | **13.6KB** | 4.1KB | ✗ **역전** |
| CI·템플릿 보유 | 대부분 | 대부분 | 대부분 | ✗ 변별력 없음 |

**해석**: 심사는 "얼마나 열심히 만들었는가"(커밋·인원·문서 분량·CI 세팅)를 보지 않는다. 그건 하위권도 다 한다. 실제로 보는 것은 **"오픈소스로서 남을 물건인가"**이며, 대리 지표는 ① 개발자 대상 여부 ② 외부 채택 증거 ③ 배포 가능한 아티팩트다.

**스타 수에 대한 주의**: 위 36.5는 수상 이후 성장분이 포함된 2026-08 시점 값이다. 별도 실측에서 **2021 금상작 ObsCare는 스타 5개·이슈 0·PR 0·CI 없음·릴리스 없음**이었고, 과거 수상작 15개의 스타 중앙값은 **2**다. 2025 은상 ODOC는 **스타 0개**로 은상을 받았다.
→ **스타 확보 활동은 완전한 낭비다. 이 대회는 스타를 보지 않는다.**

## 3. 결정적 사례 3개

### Mocka (2025 대상, 학생) — 우리의 재현 대상
Spring Boot 관계형 엔티티 Mock 데이터 자동 생성 라이브러리. **1인 팀, 레포 나이 1.4개월, 스타 2개로 대상(과기정통부 장관상)**.
- Maven Central 3개 모듈 배포(core/orm/odm), Hibernate·MyBatis·MongoDB 3개 런타임 지원
- SonarCloud Quality Gate·Coverage 배지, GitHub Actions 8종, Wiki 문서, LICENSE + **NOTICE.md 별도 관리**
- **릴리스 타임라인이 결정적**: v0.0.3(제출 마감 하루 전) → v0.0.4(10/3) → v1.0.0(10/11) → v1.2.0(11/3, 발표 전날)
- → **대회는 제출 시점이 아니라 발표 시점의 완성도로 상위상이 갈린다.** 제출용 2주는 예산의 일부일 뿐이다.

### Hot Updater (2025 대상, 일반)
React Native OTA 업데이트 솔루션. npm **월 12.2만 다운로드**, 외부 기여자 63명.
- Microsoft가 CodePush/App Center를 종료시켜 생긴 **시장 공백을 정확히 대체**. 활용성을 논증할 필요 없이 다운로드 수가 증명한다.

### Zephyr RTOS 포팅 (2025 금상, 일반)
Raspberry Pi 5 포팅 + 교육자료. **자체 코드량은 적고 기여 대상이 컸다.**
- "무엇을 새로 만들었나"가 아니라 **"무엇에 기여했나"**로 금상. 커뮤니티 확장을 부가물이 아니라 **산출물 자체**(교육자료)로 제출.
