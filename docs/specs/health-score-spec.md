# Spec: 헬스 스코어 산출

## User Scenarios & Testing
- P1: Given 서로 다른 어댑터에서 error 1건, warn 1건이 발생, When 헬스 스코어가 산출되면, Then 100 − 15 − 5 = 80점이 나온다.
- P2: Given 한 어댑터에서 error가 5건 발생(−75점 상당), When 헬스 스코어가 산출되면, Then 해당 어댑터의 감점은 −30으로 캡핑된다.
- P3: Given Docker 미설치로 어댑터가 skip됨, When 헬스 스코어가 산출되면, Then 감점 없이 분모에서도 제외되고 UI에 "해당 없음"으로 표기된다.

## Requirements
- FR-001: 100점에서 시작해 `error` 1건당 −15, `warn` 1건당 −5를 차감한다.
- FR-002: 어댑터 1개의 최대 감점은 −30으로 캡핑한다.
- FR-003: 점수 하한은 0점이다.
- FR-004: skip된 어댑터(미설치)는 감점하지 않고 분모에도 포함하지 않으며, UI에 "해당 없음"으로 별도 표기한다. 예: Docker를 쓰지 않는 사용자가 감점당하면 안 된다. 이 표기는 점수가 높은 이유가 "문제가 없어서"인지 "검사를 안 해서"인지 사용자가 구분할 수 있게 하기 위한 UI 설계 요구사항이다.
- FR-005: 등급은 90+ 정상 / 70–89 주의 / 70 미만 문제 있음으로 표시하고 펫 상태([[pet-window-spec]] §캐릭터 상태)와 연동한다.

## Key Entities
- `HealthScore`: 총점(0–100), 등급(정상/주의/문제 있음), 어댑터별 감점 내역

## Success Criteria
- 배점표(error −15, warn −5, 어댑터 상한 −30, 하한 0)가 하드코딩된 상수로 고정되어 실행마다 달라지지 않음(영상·보고서에 점수를 노출하므로 재현 가능해야 함)
- skip 어댑터가 점수 계산에서 완전히 배제됨을 단위 테스트로 검증

## Assumptions
- 없음 — 배점표가 이 문서에 완전히 확정되어 있다.
