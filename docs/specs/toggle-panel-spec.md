# Spec: 토글 패널 & fix 안전장치

## User Scenarios & Testing
- P1: Given 토글 패널에 파일 기반 문제 항목이 표시됨, When 사용자가 토글을 켜면, Then 실행될 명령 전문이 그대로 표시되고 확인 후에만 실제 수정이 실행된다.
- P2: Given `fix.needsSudo`가 `true`인 항목, When 패널이 렌더링되면, Then 토글은 비활성 상태로 표시되고 명령 복사 기능만 제공된다.
- P3: Given `fix.revert`가 없는 항목, When 실행 전 확인 단계가 표시되면, Then 되돌릴 수 없음이 명시되고 되돌리기 버튼은 비활성 상태다.
- P4: Given 파일을 수정하는 fix가 실행됨, When 실행이 완료되면, Then 원본이 `파일명.bak.<타임스탬프>`로 백업되고 재진단 후 결과가 반영된다.

## Requirements
- FR-001: 문제 목록은 스위치/토글 형태로 표시하며, 각 항목은 파일 경로·줄 번호·원문 발췌·수정 명령을 보여준다.
- FR-002: 토글을 켜면 ① 펫이 해당 토글로 걸어가 조작하는 애니메이션을 수행하고 ② 동시에 백그라운드에서 실제 수정 명령을 실행하며 ③ 재진단 후 결과를 반영한다.
- FR-003: 토글을 켜면 곧바로 실행하지 않고, 실행할 명령 전문을 그대로 보여주고 사용자 확인 후에만 진행한다.
- FR-004: 파일을 수정하는 fix는 원본을 `파일명.bak.<타임스탬프>`로 백업한 뒤 진행하며, 패널의 "되돌리기"로 복원 가능해야 한다.
- FR-005: `fix.needsSudo`가 `true`인 항목은 토글을 비활성으로 표시하고, 명령을 복사할 수 있게만 제공한다 — 권한 상승을 앱이 대신 실행하지 않는다.
- FR-006: `fix.revert`가 없는 항목은 되돌리기 버튼을 비활성화하고, 실행 전 확인 단계에서 되돌릴 수 없음을 명시한다.
- FR-007: 파일·패키지 삭제, 전역 설정 초기화 등 파괴적 작업은 v1 fix 대상에서 제외한다(설정 추가·수정, 서비스 시작 수준으로 한정).
- FR-008: 이 패널은 실제 OS 설정 화면을 조작하지 않는 자체 UI로, 화면 자동화를 사용하지 않는다.

## Key Entities
- `FixAction`: `description`, `command?`, `manual?`, `needsSudo?`, `revert?`
- `BackupRecord`: 원본 파일 경로, 백업 파일 경로(`.bak.<타임스탬프>`)

## Success Criteria
- `needsSudo` 항목에서 토글이 비활성화되고 자동 실행되지 않음을 테스트로 검증
- `revert` 없는 항목에서 되돌리기 버튼이 비활성화됨을 테스트로 검증
- 파일 수정 fix 실행 후 `.bak` 파일이 생성되고 복원이 동작함을 통합 테스트로 검증
- 파괴적 fix(삭제류)가 v1 어댑터 어디에도 존재하지 않음을 코드 리뷰/린트로 확인

## Assumptions
- 없음 — 안전장치 5종은 "10월 기능테스트에서 심사위원이 자기 머신에서 돌린다 — 선택이 아니라 필수"라는 전제에서 명시적으로 확정된 하드 제약이다.
