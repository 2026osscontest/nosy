# UI 디자인 가이드

## 디자인 원칙
1. 펫은 화면 위에 상주하되 작업을 방해하지 않는다 — 투명 배경 · 항상 위 · 프레임 없음 · 작업 표시줄 미노출. 클릭 관통(`setIgnoreMouseEvents`)은 펫 영역 밖에만 적용한다.
2. 상세 패널은 우리가 100% 통제하는 자체 UI다 — 실제 OS 설정 화면을 절대 조작하지 않는다(화면 자동화 없음, OS 버전 변화에 안전).
3. 사용자가 무엇이 실행되는지 항상 알 수 있어야 한다 — 토글을 켜기 전 실행할 명령 전문을 그대로 보여주고 확인받는다(`docs/specs/toggle-panel-spec.md` 참조).

## 캐릭터 상태 4종
| 상태 | 조건 | 연출 |
|---|---|---|
| `idle` | 모든 어댑터 정상 | 평온하게 앉아있거나 천천히 돌아다님 |
| `thinking` | 진단 실행 중 | 고민하는 모션 |
| `worried` | `warn` 있음 | 걱정하는 모션, 작은 느낌표 |
| `alarmed` | `error` 있음 또는 새 드리프트 감지 | 강한 반응 + 말풍선 자동 표시 |

등급(90+ 정상 / 70–89 주의 / 70 미만 문제 있음)이 이 상태와 연동된다.

## 인터랙션 흐름
- 클릭 → 상세 패널(토글 패널) → 재클릭 → 닫힘
- 말풍선(요약: 헬스 스코어 + 가장 심각한 문제 1건)은 `alarmed`일 때 펫이 스스로 띄운다. 말풍선이 떠 있는 상태에서 클릭하면 상세 패널로 확장된다
  - 애초에는 클릭 시퀀스가 `말풍선 → 재클릭 → 패널` 3단계였으나, 눌러 본 결과 요약을 한 번 거치는 단계가 군더더기였다 — 사용자가 펫을 누른다는 건 이미 상세를 보겠다는 뜻이고, 문제가 0건일 때는 말풍선과 패널의 내용이 사실상 같다. 말풍선은 "펫이 먼저 말을 거는" 자동 표시 연출로만 남긴다
- 토글 on 시: ① 펫이 그 토글로 걸어가 조작하는 애니메이션 ② 백그라운드에서 실제 수정 명령 실행 ③ 재진단 후 결과 반영
- 토글 패널 각 항목: 파일 경로 · 줄 번호 · 원문 발췌 · 수정 명령을 표시

## 안전장치 UI 요구사항 (`docs/specs/toggle-panel-spec.md` 참조 — 재논의 금지 수준)
1. 실행 전 확인 — 명령 전문을 그대로 보여주고 사용자 확인 후 진행
2. `fix.needsSudo === true` 항목은 토글을 비활성으로 표시하고 명령 복사만 제공
3. `fix.revert`가 없는 항목은 되돌리기 버튼 비활성 + 실행 전 확인 단계에서 "되돌릴 수 없음" 명시
4. 파일 수정은 `.bak.<타임스탬프>` 백업 후 진행, 패널에서 복원 가능해야 함

## AI 슬롭 안티패턴 — 하지 마라
| 금지 사항 | 이유 |
|-----------|------|
| backdrop-filter: blur() | glass morphism은 AI 템플릿의 가장 흔한 징후 |
| gradient-text (배경 그라데이션 텍스트) | AI가 만든 SaaS 랜딩의 1번 특징 |
| "Powered by AI" 배지 | 기능이 아니라 장식. 사용자에게 가치 없음 |
| box-shadow 글로우 애니메이션 | 네온 글로우 = AI 슬롭 |
| 보라/인디고 브랜드 색상 | "AI = 보라색" 클리셰 |
| 모든 카드에 동일한 rounded-2xl | 균일한 둥근 모서리는 템플릿 느낌 |
| 배경 gradient orb (blur-3xl 원형) | 모든 AI 랜딩 페이지에 있는 장식 |

## 색상 / 타이포그래피 / 레이아웃 / 컴포넌트 상세
**미정.** 창 동작 · 캐릭터 상태 · 패널 구조 · 안전장치만 확정되어 있고, 색상 팔레트 · 타이포그래피 · 세부 컴포넌트 스타일은 아직 다루지 않는다. 펫 캐릭터 애셋을 조달하는 시점(`docs/ADR.md` ADR-001 "애셋 조달", `docs/TIMELINE.md` D4 부근 — CC0/MIT 스프라이트 채택)에 함께 확정해야 한다. 아직 결정되지 않은 값을 여기서 임의로 채우지 않는다.

## 애니메이션
- 상태 전환 애니메이션(idle/thinking/worried/alarmed 간)과 토글 조작 시 "펫이 걸어가서 조작하는" 애니메이션은 필수다(`docs/specs/toggle-panel-spec.md` 참조).
- 그 외 easing · duration 등 세부 값은 미정 — 스프라이트 애셋 조달 시 확정한다.
